# Snow 0.3.0 — новый интерфейс macOS

Утверждённый дизайн перенесён в нативное приложение на SwiftUI и AppKit.

- Панель снежинки: выбор экранов, режим снегопада, вид и размер снежинок, ветер, четыре инструмента и переход ко всем настройкам.
- Заголовок «Поиграть со снегом» над варежкой, лопатой, снежком и удалением. Выбор инструмента в компактной панели сразу запускает игру; Esc возвращает обычную работу.
- Девять разделов полного окна: Снег, Ветер, Накопление, Поиграть со снегом, Уборка снега, Гирлянды, Экраны, Качество, Общие.
- Общие графитовые поверхности, серебристые элементы выбора, контрастные подписи, нативные ползунки с клавиатурным управлением и доступными названиями.
- Предпросмотры используют оригинальные ресурсы приложения и обновляются при изменении параметров. Это кэшированные изображения Retina без отдельного цикла анимации.
- Параметры, русский и английский языки и существующий автозапуск сохранены. Скрытые функции остаются скрытыми.
- Команды скрытия, очистки, выбора языка и выхода доступны в меню «…». Прежнее системное меню открывается правым кликом по снежинке. Быструю панель также можно открыть командой «Быстрые настройки» или сочетанием ⌘⌥, при активном приложении.

## Проверки

- Debug и Release собраны Xcode; Universal содержит arm64 и x86_64.
- 109 тестов SnowCore прошли без ошибок.
- 91 встроенная проверка возможностей и локализации прошла.
- 16 проверок жизненного цикла прошли.
- Отрисованы девять вкладок, меню и английский экран. 11 проверок UI, включая сохранение через настоящий NSSlider и общий SettingsStore компактной панели, прошли.
- В запущенном приложении проверены вкладки, выпадающее меню экранов, отмена сброса, открытие компактной панели, запуск варежки и выход по Esc.
- Подпись проверена через `codesign --verify --deep --strict`; DMG проверяется при упаковке.

Сборка: `build/Release/Snow.app`. Установочный файл: `build/Snow-0.3.0-universal.dmg`.

Нативные снимки: `build/settings-previews/`. Журналы: `build/logs/`. Снимки для проверки создаются отдельной командой без изменения пользовательских параметров:

```sh
build/Release/Snow.app/Contents/MacOS/Snow --render-settings "$PWD/build/settings-previews"
```

Запуск на настоящих Intel и macOS 12 отдельно не проверялся; целевая совместимость сохранена.
