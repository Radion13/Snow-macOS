# Снег для Windows

`0.2.19-win.1` — самостоятельная Windows x64-версия на C++17, Win32 и GDI+, синхронизированная с macOS 0.2.19. macOS-приложение не изменялось.

**[Скачать установщик Windows x64](https://github.com/Radion13/Snow-macOS/raw/refs/heads/windows/downloads/SnowSetup-0.2.19-win-x64.exe)** · [Сборка и исправления на Windows](docs/DEVELOPMENT.md)

Для передачи нужен один файл: [SnowSetup-0.2.19-win-x64.exe](downloads/SnowSetup-0.2.19-win-x64.exe). Получатель запускает мастер на Windows 10/11 x64. Установка для текущего пользователя, без интернета, .NET и прав администратора, в `%LOCALAPPDATA%\Programs\Snow`. Ярлыки находятся в «Пуск»; автозапуск выключен. Удаление доступно в списке установленных приложений. [Контрольная сумма](downloads/SHA256SUMS.txt) позволяет проверить файл.

Это Windows-версия на основе macOS 0.2.19. Новый графитовый интерфейс и четыре снеговика macOS 0.3.9 в неё ещё не перенесены. Текущая публикация нужна для проверки Windows-багов и дальнейших исправлений.

## Открыть в Codex на Windows

```powershell
git clone --branch windows --single-branch https://github.com/Radion13/Snow-macOS.git Snow-Windows
cd Snow-Windows
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Windows.ps1 -Smoke
```

Windows-исходники находятся в отдельной ветке `windows`; корень этой ветки — самостоятельный Windows-проект. Нужны Visual Studio с C++, Windows SDK и CMake. Откройте папку `Snow-Windows` в Codex: `AGENTS.md` содержит команды сборки и проверки. Приложение запускается из `dist-native/Snow/Snow.exe --settings`, отчёты диагностики сохраняются в `build/diagnostics`. Подробности — в [инструкции разработчика](docs/DEVELOPMENT.md).

## Что перенесено

- Простой и фактурный снег, простой вид по умолчанию; объёмные снежки, лицо и шарф фактурного снеговика, частичная боковая ручка ведра. Центральных точек на шарах нет.
- Простые снежинки и восемь узорных форм с размером 50–300%, независимым сохранением и стабильной формой в полёте. Reduce Motion отключает вращение.
- Пять новых векторных ёлочек с размером +25%, шестью расстановками по всему нижнему краю, ростом, миганием и золотистыми звёздами. Контуры скомпилированы из [SVG Mac-версии](assets/tree-vector.svg) и один раз рисуются в пять общих слоёв. Геометрия ёлочек и схемы совпадают с macOS 0.2.19.
- Снежок создаётся по нажатию; катание и сборка снеговика; быстрый бросок к стеклу с девятью вариантами тающих клякс. Установка шара имеет приоритет перед броском.
- Варежка переносит снег и может поднять горсть. С края окна снег падает ниже, сохраняя переносимую площадь и ограниченный бюджет частиц. Сугробы имеют бугры; снег огибает закругления.
- Два трактора, стекло позади колёс, вращение колёс, передний ковш, ручной и автоматический проход. Удаление опоры опускает снеговика целиком.
- Три экранные гирлянды с яркостью и интенсивностью. Актуальные названия «Уборка снега», «Запустить уборщика», «Растопить весь снег», «Показать Ёлочки». Метла в боковом меню. Описание ветра под заголовком; ползунки без повторных подписей.
- Скрыты зимние сцены, изображение на ковше и виджеты. Старые данные сохранены, скрытые эффекты не активируются.

Обычный слой пропускает мышь. Игра включается явно; Esc возвращает обычный ввод. Сон, блокировка, скрытие, пауза и полноэкранные окна управляют жизненным циклом. Используются границы окон, без их заголовков и содержимого. Сетевого клиента, службы и обновлений нет.

## Проверка и ограничения

[Отчёт проверки](docs/VALIDATION.md) содержит результаты модели, запуска Windows-приложения через Wine, установки и удаления, формата PE и контрольные суммы. Wine не заменяет настоящую Windows. Физические мониторы, несколько DPI, реальная панель задач и системные полноэкранные приложения требуют отдельной приёмки. Подписи Authenticode пока нет.

Windows использует область уведомлений и панель задач вместо строки меню и Dock macOS. Материалы и снежинки рисуются GDI+, поэтому сглаживание может отличаться. SVG ёлочки содержит те же контуры; материалы, формы и кляксы используют ограниченный кэш. Нагрузка при 60 кадрах/с зависит от разрешения экрана и программного рендеринга GDI+; длительных замеров батареи не проводилось.

## Сборка

На Apple Silicon нужны Python 3 и Xcode Command Line Tools:

```sh
./scripts/build.sh
```

Скрипт проверяет SHA-256 закреплённых Zig и NSIS, совпадение векторного заголовка с SVG, запускает тесты модели, собирает приложение и NSIS-установщик, проверяет PE, ресурсы и системные зависимости. `.tools` и `build` передавать не нужно. Для переносного запуска отправляйте всю папку `dist/Snow`.

На Windows с Visual Studio, C++ и Windows SDK:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Windows.ps1 -Smoke
```

`Test-Windows.ps1` по умолчанию проверяет последнюю собственную сборку из `dist-native/Snow`. Параметр `-Executable ...` проверяет выбранную установленную копию. Перед диагностикой нужно завершить обычный экземпляр приложения. В репозитории есть автоматическая Windows-сборка и проверка через GitHub Actions.

Для проверки через Wine: `python3 scripts/bootstrap.py --wine`. Wine хранится внутри `.tools`, использует отдельный префикс проекта и не входит в установщик.

## Исходники

`src/core.hpp` — модель; `drawing.hpp` и `effects-drawing.inc` — отрисовка; `tree-vector.inc` — пути из SVG; `main.cpp` — окна и настройки; `previews.hpp` — экспорт рендеров. `scripts/generate-tree.py` выводит заголовок из SVG; сборка проверяет его совпадение. Лицензии инструментов — в [THIRD_PARTY.md](THIRD_PARTY.md).
