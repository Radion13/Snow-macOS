# Snow 0.3.1 — исправления меню и игры

- «Свет» и «Палитра» гирлянд используют полноценный нативный NSPopUpButton. Нажатие работает по всей поверхности, включая стрелку; выбранное значение применяется и сохраняется. Прозрачный элемент под декоративной накладкой удалён.
- Размер компактной панели рассчитывается по доступной области экрана, на котором находится значок. Высота ограничена; содержимое прокручивается на небольшом экране. Положение окна дополнительно удерживается внутри видимой области.
- Лопата скрыта в компактной панели, разделе игры и системном меню. Код и механика сохранены за флагом `SnowAppFeatures.shovelTool`.
- Кнопка «Начать игру» убрана. Варежка, снежок и удаление включаются при выборе инструмента. Esc завершает режим игры.
- В «Общие» добавлена ссылка «Создатель D1on» → https://t.me/Radion013.
