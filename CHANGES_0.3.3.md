# Snow 0.3.3 — переключатель снегопада и выход из игры

- Переключатель «Лёгкий / Ровный / Метель» перенесён над областью предпросмотра, сразу под выбором экранов.
- Повторное нажатие на выбранный игровой инструмент завершает игру без Esc. Меню остаётся открытым, выделение снимается, окна снега снова пропускают клики на рабочий стол. Следующий клик запускает игру снова.
- Обработчик Esc сохранён как альтернативный способ выхода.

Сборка: `build/Release/Snow.app`. Установочный файл: `build/Snow-0.3.3-universal.dmg`.

Проверки и снимки: `build/logs/*-0.3.3.log`, `build/settings-previews-0.3.3/`.

- 20 проверок жизненного цикла прошли в Debug и Release. Проверены оба инструмента, открытое меню во время игры, выключение повторным нажатием, снятие выделения, освобождение ввода, повторный запуск и прежний выход через Esc.
- 18 проверок интерфейса и 3 проверки настоящего NSPopover прошли. Новое расположение переключателя также проверено визуально в запущенном приложении.
- Готовая Universal-сборка содержит arm64 и x86_64; проверка подписи и целостности DMG прошла.
