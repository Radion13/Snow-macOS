# Исходная Windows-сборка для тестирования

`SnowSetup-0.2.19-win-x64.exe` — готовый установщик 0.2.19-win.1 для Windows
10/11 x64. Программа опубликована без изменения исходного бинарного файла,
чтобы воспроизводить существующие баги на настоящей Windows.

В PowerShell из этой папки:

```powershell
Get-FileHash .\SnowSetup-0.2.19-win-x64.exe -Algorithm SHA256
```

Результат должен совпасть с `SHA256SUMS.txt`. Новые исправления собираются
из исходников в `dist-native/Snow`; этот установщик не обновляется автоматически.
